Executive Summary

The research has reduced a direct PGS route to Brocard's conjecture to explicit endpoint-chain inequalities after a prime square. The current strongest bridge is not a classical prime-density estimate. It is a local chamber statement about the first four exact divisor-count endpoint arrivals after a^2.

For a prime root a, let u1,u2,u3,u4 be the offsets of the first four later integers with exact divisor count 2. The sufficient half-wall target is:

u4 = e4(a) - a^2 < 2a  for prime roots a >= 11.

The high-root surface now reduces this target to three proof obligations:

square-tail quarter:   u1 < a/4
dominant-tail third:   M = max(c2,c3,c4) < a/3
residual-pair sixth:   R = c2+c3+c4-M < a/6

On the exact measured surface through prime root 99991, all three obligations have zero failures. Brocard's conjecture is not claimed solved. The claim is that the PGS track has found a concrete proof program with falsifiable local lemmas.

Problem Statement

Brocard's conjecture states that for consecutive primes a < b, with the usual exclusion of the first small pair, the interval (a^2,b^2) contains at least four primes.

The PGS translation is:

Start at the prime square a^2.
Let e1,e2,e3,e4 be the first four later exact divisor-count endpoints.
Prove e4 < b^2.

A stronger sufficient statement is e4(a) - a^2 < 2a for a >= 11, because consecutive odd primes satisfy b >= a+2, hence a^2 + 2a < (a+2)^2 <= b^2.

PGS Object Definitions

Endpoint Offsets

For a prime root a, define the endpoint offsets after the square wall:

ui = ei(a) - a^2,
where tau(ei(a)) = 2
and e1 < e2 < e3 < e4.

Tail Components

The endpoint-chain components are:

c1 = u1
c2 = u2 - u1
c3 = u3 - u2
c4 = u4 - u3

The high-root proof uses u1 as the square-tail term and c2,c3,c4 as the post-first endpoint-chain tail.
