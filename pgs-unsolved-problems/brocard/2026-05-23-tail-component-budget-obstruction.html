Brocard PGS proof-tree update

The equal per-component tail budget is false; the Brocard tail proof must be aggregate.

On the exact endpoint surface through prime root 99991, five high-root rows violate the natural componentwise bridge c2,c3,c4 < a/6. The aggregate chain-tail half bridge still has zero failures, so the live proof obligation is no longer an equal split across the three post-first endpoint components.

Endpoint Chain

For a prime root a, start at a^2. Let e1,e2,e3,e4 be the first four later exact divisor-count endpoints with tau(n)=2.

ui = ei - a^2
c1 = u1
c2 = u2 - u1
c3 = u3 - u2
c4 = u4 - u3

Live Half-Wall Split

The high-root proof target is split into a square-tail quarter budget and a post-first endpoint-chain half budget.

square tail: u1 < a/4
chain tail:  c2 + c3 + c4 < a/2
therefore:   u4 < 3a/4 < 2a

Formal Branch Tested

The attempted bridge was the equal component budget:

c2 < a/6, c3 < a/6, c4 < a/6
=> c2 + c3 + c4 < a/2.

This would have supplied a direct proof route for the chain-tail half lemma. It is false on the current exact surface, so it is now an invalidated proof branch.

Proof-State Change

The equal-split route is removed from the Brocard proof tree. The measured failures occur in every tail position class: once in c2, twice in c3, and twice in c4. They also occur in both prime-square residue classes 1 and 19 modulo 30. A residue-only or fixed-position proof of the component budget does not match the obstruction.

The live proof obligation is now one of two sharper statements:

1. threshold route:
   prove c2,c3,c4 < a/6 for all a >= 167,
   and close 101 <= a < 167 by direct finite endpoint rows.

2. aggregate route:
   prove c2 + c3 + c4 < a/2 directly,
   allowing one large endpoint-chain component only when the other two
   tail components compensate.

The second route is the cleaner PGS-native target because every invalidating row keeps the aggregate chain-tail half inequality with positive slack.
