Executive Summary

The primary proved object is the GWR carrier: in a nonempty prime-gap interior, exact divisor counts select the leftmost integer with minimum tau. The Divisor-Field Extremals track asks which secondary fields are forced, forbidden, or conditionally aligned after that carrier has already been selected.

The central current result is a branch reduction. For tau-4 carriers, the proposed one-way secondary bridge says that a later higher-tau competitor which lowers sigma(n)/n also lowers the phi deficit. A sigma-only counterexample must pass a deficit-headroom gate and then an overlap-floor gate. The latest run proves the overlap-floor exclusion lemma, proves that pure prime-power competitors cannot pass the gate, and measures that all 24,210 deficit-band entrants through q <= 10,000,000 are eliminated by the overlap floor.

Problem Statement

For consecutive primes p < q, define the gap interior

I = {p + 1, ..., q - 1}.

For n in I, let tau(n) be the divisor count, sigma(n) the divisor sum, omega(n) the number of distinct prime factors, and phi(n) Euler's totient. The GWR carrier is

w = min { n in I : tau(n) = min(tau(m) : m in I) }.

The research question is not whether sigma, omega, or phi can choose w. They do not choose it. The question is which secondary extremal roles remain forced or forbidden once w has been fixed by the proved tau rule.

Current Lemma Target

Define the downstream loads

E(n) = (sigma(n) - n) / n
D(n) = (n - phi(n)) / n
H(n) = E(n) - D(n).

A later higher-tau competitor t can be a sigma-only counterexample against a tau-4 carrier w only if

D(w) <= D(t) < E(w)
H(t) < E(w) - D(t).

The latest overlap-floor lemma says that if L(t) >= E(w)-D(t), then t cannot be a sigma-only counterexample. Here L(t)=1/r^2 for repeated-smallest-prime channels and L(t)=2/(rs) for distinct smallest prime channels.

The remaining proof target is exact and falsifiable: prove L(t) >= E(w)-D(t) for every non-prime-power deficit-band entrant, or exhibit one row where it fails.

Relation To Outside Literature

Nearby public literature studies divisor functions on short intervals, arithmetic functions at shifted primes, rough numbers in prime gaps, and prime-gap size. Those are adjacent but do not appear to classify secondary divisor-field extremal roles conditioned on the GWR tau carrier inside each prime-gap interior.

  • Erdos and Hall, Values of the Divisor Function on Short Intervals
  • Pollack and Thompson, Arithmetic functions at consecutive shifted primes
  • Gafni and Tao, Rough numbers between consecutive primes
  • Zhang, Bounded gaps between primes

The reviewer-facing claim is therefore scoped: this track is not a solved classical theorem. It is a developed, falsifiable PGS-native program for a carrier-conditioned secondary divisor-field problem that appears underrepresented in the public literature.
