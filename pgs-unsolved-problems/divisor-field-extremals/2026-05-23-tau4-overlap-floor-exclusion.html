Overlap-Floor Lemma

Let t be a later higher-tau competitor in the same gap as a tau-4 carrier w. A sigma-only counterexample must satisfy D(t) >= D(w) and E(t) < E(w). Since E(t)=D(t)+H(t), it must also satisfy

H(t) < E(w)-D(t).

The overlap expansion gives a direct lower bound for H(t). If t contains a repeated smallest prime channel r^2, then H(t) >= 1/r^2. If the two smallest prime channels are distinct r < s, then H(t) >= 2/(rs). Call this lower bound L(t).

Overlap-floor exclusion. If L(t) >= E(w)-D(t), then E(t) >= E(w). Therefore t cannot be a sigma-only counterexample.

Prime-Power Branch

The pure prime-power competitor branch is eliminated at theorem level. If t=s^e with e >= 4, then D(t)=1/s and H(t)=1/s^2+...+1/s^e.

For a semiprime carrier w=uv, D(w)=(u+v-1)/(uv) and the maximum possible headroom is E(w)-D(w)=2/(uv). The condition D(t)>=D(w) gives s <= uv/(u+v-1). Since 2uv < (u+v-1)^2, this forces 1/s^2 > 2/(uv), so H(t) exceeds the headroom.

For a prime-cube carrier w=r^3, D(w)=1/r and the maximum possible headroom is 1/r^2+1/r^3. If s=r, then H(t) contains both terms. If s<r, then s<=r-2 for odd primes and 1/s^2 > 1/r^2+1/r^3; the case r=3,s=2 satisfies the same inequality directly. Thus a pure prime-power t cannot pass the sigma-only headroom gate.
