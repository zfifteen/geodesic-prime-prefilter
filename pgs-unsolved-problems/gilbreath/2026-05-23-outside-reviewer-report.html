Executive Finding

The strongest supported claim is that the PGS track has produced a nontrivial structural proof program for the actual prime sequence. It has eliminated several attractive but false shortcut bridges and isolated a sharper live theorem target: high low-prefix boundary pairs must be reserve-separated from the floor, while the floor boundary must reset through 2,4.

This is not a solution of Gilbreath's conjecture. It is a proof-state advance: a broad finite-difference problem has been converted into explicit PGS obligations that outside reviewers can inspect, falsify, or attempt to prove.

Problem Statement

Start with the prime sequence. Replace each row by the absolute differences of adjacent entries, then repeat. Gilbreath's conjecture states that the first entry of every later row is 1.

In PGS language, the first difference row is the ordered endpoint-gap sequence. At depth k, the first k + 1 endpoint gaps determine the leading value of the kth absolute-difference row. The core target is therefore prefix admission:

For every depth k, the actual seeded PGS gap prefix W_k satisfies Delta^k(W_k)_0 = 1.

Proof-Tree Summary

1. Prefix Admission

For depth k, only the first k + 1 ordered endpoint gaps determine the leading value. The problem becomes membership of actual PGS prefixes in L_k = {W : Delta^k(W)_0 = 1}.

2. Left-Edge Parity Gate

Once the leading value is 1 and all non-leading lanes are even, the next row leads with 1 exactly when the next lane is 0 or 2.

3. Low-Prefix Corridor

Let ell count consecutive non-leading left lanes in {0,2}. Ordinary depletion lowers this reserve by at most one per row. Resets replenish it.

4. Reset Boundary

Measured positive resets begin at boundary pair 2,4. This is the current concrete floor-reset target.

5. Fold-Transfer Guard

The right-edge diagonal converts prefix extension into a backward ceiling condition. If the absorbing guard holds, admitted next gaps form an initial even interval.

6. Reserve Separation

Actual high boundary pairs such as 2,6 occur, but only with large low-prefix reserve on the measured surface. The floor case remains guarded by 2,4.

Expected Reviewer Questions

QuestionCurrent answer
Does this prove Gilbreath? No. It identifies and measures a proof route. The missing theorem is all-scale reserve separation from PGS endpoint-gap grammar.
Is this only computational verification? No. The finite probes support formal reductions and falsify candidate bridges. The measurements do not establish the theorem.
Why is the 2,6 result important? Because it blocks an over-strong bridge. Actual PGS allows 2,6, so a proof must explain reserve placement, not merely forbid a boundary pair.
What must be proved next? For every actual seeded PGS cascade row: if ell = 2, the boundary pair is 2,4; if the boundary pair is high, then ell >= 3, with enough reserve for ordinary depletion.
What would falsify the current route? An actual seeded endpoint-gap row with a high boundary at floor reserve, or an actual transfer-guard/ceiling failure, would force a new bridge.
