Bridge Lemma

Statement

If floor(N / L) = U and floor(N / U) = L, then the one-side drop floor((N - 1) / L) = U - 1 proves N = L * U. The symmetric upper drop is useful as a mirrored public certificate, but the lower drop already forces the cell to its left boundary.

Proof

From floor(N / L) = U, the reciprocal floor cell gives L * U <= N. From floor((N - 1) / L) = U - 1, it gives N - 1 < L * U, hence N <= L * U. Therefore N = L * U, so L and U are factor endpoints. This is theorem proof conditional on the public boundary-drop field being admitted or derived.
