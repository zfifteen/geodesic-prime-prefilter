2026-05-14 research note

NLSC lower-divisor deadlines do not bridge the dominant square chamber

The No-Later-Simpler-Composite route gives a valid endpoint deadline only when a later composite with strictly smaller divisor count exists before the next square boundary. In the dominant d(w)=4 regime, the required smaller composite would be a prime square, and no square lies strictly between n^2 and (n + 1)^2.

PGS Objects

Square Chamber

Fix an integer n > 1. The Legendre chamber is the open interval (n^2, (n + 1)^2).

Containing Prime Gap

Let p < n^2 < q be the consecutive-prime gap containing the square start, when the right endpoint has not already arrived inside the chamber.

Selected Integer

Let w be the Leftmost Minimum-Divisor Rule witness in the gap interior: the first interior integer carrying the minimum divisor count.

NLSC Closure

Once w appears, the gap closes before any later interior composite with divisor count strictly below d(w).

Bridge Tested

The proposed bridge was:

Bridge shape Find a square-chamber integer t with n^2 < t < (n + 1)^2, w < t, and d(t) < d(w). Then NLSC forces q ≤ t < (n + 1)^2.
Why it would work If no prime endpoint arrived before t, then t would be a later simpler composite inside the same gap, contradicting the GWR/NLSC closure law.
PGS status The implication is valid when such a lower-divisor deadline t exists. The existence clause is the bridge load.

Falsification

Dominant regime The current GWR/DNI and gap-ridge materials identify d(w)=4 as the dominant selected-divisor-count regime, with first-d=4 arrival under square exclusion on the documented surfaces.
Lower class For a composite integer, d(t) < 4 means d(t)=3. Those composites are exactly prime squares.
Square chamber fact There is no integer square strictly between consecutive integer squares n^2 and (n + 1)^2. Therefore there is no prime square inside the open Legendre chamber.
Result Invalidated bridge: NLSC plus a lower-divisor composite deadline cannot force next_prime(n^2) < (n + 1)^2 in the dominant d(w)=4 chamber.

Research Consequence

The Legendre track needs a bridge that acts before strict divisor-count descent. For the dominant chamber, the useful target is no longer a lower-divisor deadline. The next proof target must bind endpoint arrival to one of these PGS-native objects:

Equal-class pressureShow that repeated or early d=4 availability inside the square chamber forces endpoint closure before the next square boundary.
Left-bound positionRelate the containing gap's left endpoint p, selected integer w, and square start n^2 so the GWR winner cannot sit too far before the chamber without endpoint arrival.
Square-tail obstructionAdapt square-branch obstruction work to show that a gap spanning an entire Legendre chamber would create an impossible square-tail profile.
