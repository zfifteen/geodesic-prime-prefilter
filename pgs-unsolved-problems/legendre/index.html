Square-chamber occupancy

Legendre's Conjecture

This track asks whether PGS can force next-prime endpoint arrival inside every interval between consecutive integer squares.

status: bridge falsification recorded claim status: unresolved latest run: ADVANCE

Original Problem

For every positive integer n, there exists a prime number strictly between n^2 and (n + 1)^2.

PGS Translation

Object

The interval (n^2, (n + 1)^2) is treated as a square-bounded chamber on the integer line.

Endpoint Form

The target becomes next_prime(n^2) < (n + 1)^2, expressed through deterministic endpoint arrival rather than probabilistic prime density.
