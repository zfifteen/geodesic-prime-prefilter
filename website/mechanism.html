02 · Mechanism

How PGS works

Count the positive divisors of each integer after a known prime. The first time that count is exactly two, you have the next prime. Inside the gap, the first integer with the smallest divisor count is a distinguished landmark.

The walk after a known prime

You are given a prime p. Look at p+1, then p+2, then p+3, and so on. For each integer, compute how many positive divisors it has.

An integer greater than 1 is prime exactly when it has two positive divisors: 1 and itself. So the first later integer whose divisor count is 2 is the next prime. Call it q.

Mechanism in one sentence

Exact divisor counts, read in increasing order after p, locate q without treating the process as a random candidate lottery.

Endpoints and selected witness

The landmark inside the gap

When the gap has a nonempty interior, scan the composites from left to right. Find the smallest divisor count that appears. Then take the first integer that achieves it.

That integer is the selected witness. In project language it is the left-hand side of the Leftmost Minimum-Divisor Rule (also called GWR in the research documents). The course will keep using the plain phrase first: leftmost minimum-divisor integer.

Why care? Because the program proves that this simple selection is not arbitrary: it is the unique maximizer of a fixed comparison score built from the divisor count and the size of the integer.

Write τ(n) for the number of positive divisors of n. Then

\[ q = \min\{ n > p : \tau(n) = 2 \} \]

On a nonempty interior I, the selected witness is

\[ w = \min\{ n \in I : \tau(n) = \min_{m \in I} \tau(m) \} \]

The comparison function used in the proof is

\[ F(n) = \left(1 - \frac{\tau(n)}{2}\right)\log n \]

Equivalently, in zero-excess coordinates, \( E(n) = \bigl(\frac{\tau(n)}{2} - 1\bigr)\log n \) and \( F(n) = -E(n) \). Primes are exactly the zero-excess integers for n > 1.

What this is not

The mechanism is deterministic. It is not a probability story about “likely primes,” and it is not a confidence score. Classical primality tests can still appear later as audit tools. They do not choose the structural answer.
