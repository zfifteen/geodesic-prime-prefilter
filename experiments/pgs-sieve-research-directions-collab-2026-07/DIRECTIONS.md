# PGS × Sieve Research Directions: Status Map

This document provides a status grid for the five core research directions mapping the intersection of Prime Gap Structure (PGS) and classical sieve theory.

**Parent Status:** D1 is currently measured on R0; the execution collab remains open with a gap-width redesign pending kill-shape adjudication.

| # | Direction | Focus | Current Status |
| :--- | :--- | :--- | :--- |
| **D1** | **Bounded-gap interior atlas** | Measuring GWR geometry inside gaps with $q - p \le H$ compared to typical gaps. | **measured on R0** (redesign pending adjudication) |
| **D2** | **Admissible k-tuples as divisor-field labs** | Reading out PGS interior structure on known constellation/admissible hits (sampling, not generating). | **hypothesis** |
| **D3** | **Sieve weights via DNI/excess** | Exploring correlations between sieve weights and DNI/excess. High-risk, classical comparison only. | **hypothesis** |
| **D4** | **Two bounds, one story** | Bridging the dual bounds: universal compression (PGS theorem) vs gap size i.o. (Zhang–Maynard). | **bridge note / comparison** (PGS compression is theorem; Zhang–Maynard is classical comparison; the bridge document is not a theorem) |
| **D5** | **Sieve moduli vs modulus-link residual cells** | Establishing a dictionary or explicit negative result between sieve moduli and residual cells. | **unresolved / optional** |

**Status Definitions:**
*   **theorem:** Mathematically proven within the PGS framework under stated hypotheses (requires `PROOF.md` backing).
*   **measured:** Verified against executing $10^{18}$ surface data.
*   **hypothesis:** Plausible structural behavior, awaiting test regime definition and measurement.
*   **measured on R0:** Measured on R0 only; not verified.
*   **unresolved:** Open question, requires conceptual scoping.
*   **invalidated:** Proven false or rejected by hard contracts (e.g., Super-Signal).
*   **optional:** Can be deferred or concluded with a clean negative result without blocking the core effort.
