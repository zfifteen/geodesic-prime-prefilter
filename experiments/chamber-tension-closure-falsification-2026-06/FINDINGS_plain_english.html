What This Experiment Found

Plain-English companion to FINDINGS.md  ·  Executed 2026-06-19  ·  Experiment design (revision 4)

Bottom line: The chamber-tension closure idea is still unresolved. We did not prove it. We did not disprove it either. What we did confirm is narrower: the production next-prime rule works exactly as already proved and implemented, and the alternative paths we tested do not yet show a way to predict the next prime without using the same divisor-count selection the proved theorem already uses.

What we were trying to learn

The chamber-tension closure hypothesis asks a forward-looking question. Start at a known prime p. Walk right along the integers until you reach the next prime q. Along that gap, composites sit above a floor where primes have no excess. The hypothesis imagines that this interior “load” or tension might be enough, by itself, to tell you where q must land, before you identify q by checking which number has exactly two divisors.

Divisor count (written τ in the technical notes) would then be only a check, not the engine of the prediction. That is the substantive claim. This experiment was built to test whether any tested forward path actually delivers that independence.

What was already proved (unchanged)

Separately from this experiment, the project already has a proved deterministic law: the next prime after p is the smallest integer greater than p whose divisor count is exactly two. The leftmost minimum-divisor rule (GWR) picks the same answer inside each gap chamber. Those results live in PROOF.md. This experiment does not weaken or strengthen them.

How we tested it

We ran three tiers of checks, plus a deliberate wrong answer as a sanity control.

The sanity control (F0). We tried a naive guess: take the GWR offset inside the gap and add it directly to p. That shortcut matched the true next prime zero times out of 78,493 consecutive gaps between 11 and one million. Good : a broken rule should fail, and it did.

Tier A, does production Rule X match the proved selector? On the same 78,493 gaps, with the search bound set to the actual gap width, production Rule X returned the correct next prime every single time. A post-hoc audit confirmed every output had divisor count two. That supports implementation correctness on this surface. It does not prove the chamber-tension story. It confirms what the proved theorem and existing generator already say.

Tier B, is a rewritten version of Rule X any different? We rewrote the selector so it never literally branches on “divisor count equals two,” using equivalent “not greater than two” logic instead. It matched Tier A on all 78,493 gaps. That was expected. It is a notational refactor, not a new physical mechanism.

Tier C, can we close the chamber by ruling out composites next door? On anchors from 11 through 10,000, with a fixed bound of 64, we asked whether eliminating adjacent composites leaves exactly one survivor at the chamber boundary. The answer was no: zero out of 1,225 rows produced a single uniquely resolved survivor. In every case, the boundary did not narrow to one candidate under the default exclusion rules. No true boundary was wrongly rejected.

Prefix forcing. We also asked whether stopping one step short of the full gap width ever resolves early. It never did on the full run. On a sample of 158 gaps, the decision always landed exactly at the gap width, not before it.

Production-bound repeat (R1). We reran the gap tests with a fixed bound of 128 instead of the true gap width. Same match rates. No gap in this range exceeded 128, so the bound never clipped a real answer.

What this does and does not mean

Supported on tested surfaces: Production Rule X matches the proved next-prime selector on the regimes we ran. The F2-RX rewrite is equivalent to Rule X there. The GWR-offset negative control fails everywhere, as it should.

Not demonstrated: A forward chamber law that predicts q without relying on divisor-count selection equivalent to Rule X. Tier C’s composite- exclusion path did not produce unique boundary survivors under the pre-registered rules. Prefix forcing did not show early closure before the full gap.

Not falsified: We never saw a case where the true next prime was rejected at the tier C boundary. We never saw production Rule X miss on the R2 surface. So the parent hypothesis is open, not dead.

Read this carefully: Perfect scores on Tier A and Tier B are not evidence for chamber-tension closure. They are evidence that the existing proved rule and its implementation still agree. Tier C’s zero unique survivors is not a failure of the experiment, it is an honest measured result that leaves the substantive forward prediction question open.

The numbers in one place

Consecutive gaps tested (R2 and R1): 78,493, for primes from 11 up to just below one million. F0 wrong-guess matches: 0. Rule X and F2-RX correct matches: 78,493 (100%). Tier C rows: 1,225. Unique resolved survivors at the boundary: 0. Cases where the boundary could not narrow to one candidate: 1,225. True boundaries wrongly thrown out: 0.
