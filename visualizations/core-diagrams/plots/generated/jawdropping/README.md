# Historical plot experiments (non-catalog)

**Status:** editorial / historical art only. Not a catalog claim surface.
**Do not** treat these files as theorem proof, measured validation, or program-level evidence.

Generated mid-2026 as exploratory matplotlib/plotly experiments. The professional
scientific demos live in `visualizations/library/` and
`visualizations/gallery/`.

## What is here

Aesthetic and interactive renders built from small-scale PGS-related fields
(divisor counts, GWR selection illustrations, square-branch audit points).
Scripts under this tree may use classical helpers (for example sympy) for
plotting. That is teaching/art packaging, not PGS inference.
