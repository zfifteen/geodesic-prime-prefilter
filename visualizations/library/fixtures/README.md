# Fixtures

Tiny teaching inputs for plot demos.

- `exemplars/gaps.json` — small prime pairs for chamber plots.
- `surfaces/generator_surfaces.json` — published aggregate counts mirrored from
  `docs/RESULTS.md` for scoreboard demos (not a substitute for raw ladder artifacts).

Large research surfaces stay under `research/*/output/` and are referenced by path
from future entries rather than copied here.
