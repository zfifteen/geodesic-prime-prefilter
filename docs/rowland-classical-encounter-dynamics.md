# Rowland Recurrence: Classical Encounter Dynamics vs PGS Next-Prime Operator

This document provides a strict category split between Eric Rowland's gcd recurrence and Prime Gap Structure (PGS). It exists to clarify literature boundaries and prevent classical primality-inference methods from bleeding into PGS structural contracts.

## The Category Split

| Feature | Rowland's Recurrence (Classical) | PGS (Structural) |
| :--- | :--- | :--- |
| **Domain** | Sequence values / return maps | Ordered divisor field / Prime-square proximity |
| **Output Type** | Emits primes as values (along with 1s) | Identifies exact structural positions of primes |
| **Mechanism** | $a(n) = a(n-1) + \gcd(n, a(n-1))$ | Universal Bounded Compression (UBC), Next-Prime Law |
| **Prerequisite** | Implicit primality testing (largest/smallest prime divisors) | Known prime state, bounded residual tracking |
| **Core Nature** | Dynamical system encountering primes | Deterministic structural geometry forcing primes |

## The "Category Error" Diagnosis

It is a category error to treat Rowland's recurrence as an alternative to the PGS next-prime operator.

1. **Audit vs. Inference**: Rowland's recurrence requires knowing the smallest prime divisor of $2n-1$ to skip trivial steps. This makes it a classical candidate factory—it requires external primality testing/factorization to function efficiently. PGS demands that structure is emitted first (via residuals), and primality is an audited consequence, not an inference driver.
2. **Values vs. Indices**: Rowland relies on values generated by the sequence. PGS relies on the structural indices and the resulting residual map. Focusing on the values of the recurrence (e.g., the primes that appear) distracts from the index law that actually governs prime occurrence.
3. **Return Map vs. Next-Prime Operator**: Rowland's sequence is a dynamical return-map that *happens* to land on primes. A true PGS operator is a strict `known p \to next q` contract based on gap structures.

## Explicit Rejections

To maintain the integrity of the PGS architecture, specifically the `rsa-v3` inference path, the following are explicitly rejected:

- **Recurrence generator in solver**: Rowland's generator (or similar gcd variants) will not be used in any PGS solver or next-prime generation code paths.
- **LCM residual discriminator**: Cloitre's LCM variant is empirical and lacks a structural certificate. It will not be used as a residual discriminator.
- **Shortcut-as-PGS**: Classical shortcuts that rely on factorization (like skipping 1s in Rowland's sequence) are fundamentally incompatible with PGS's "audit later, never primality-driven search" discipline.

## Resolution on Event-Cluster Probing

We will **not** open a PGS-native event-cluster probe into the Rowland clusters. Rowland's sequence will be maintained strictly as a **literature contrast**. 

**Justification**: The live open question in PGS is resolving the **public residual vs. endpoint class** for RSA constraints. Diverting resources to map Rowland's log-scale geometric clusters—which are artifacts of the size of the next prime divisor of $2n-1$—is a distraction from true residual mapping. The clusters represent a classical residual taxonomy (long excursion = large obstruction, short excursion = small obstruction), but tracing them requires classical factorization, which violates the PGS mandate.
