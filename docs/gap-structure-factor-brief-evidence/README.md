## Working Title

From Prime Gaps To Factor Recovery: What Has Been Built, What Is Still Missing

## Purpose

This folder collects the support for a ten-panel external research status
brief. Each paragraph gets its own evidence packet before public prose is
written.

The brief should explain the work without project jargon first. Internal terms
are allowed only after the underlying object has been described plainly.

## Evidence Rules

- Keep theorem proof, implementation status, measured result, audit result,
  hypothesis, unresolved state, and invalidated rule separate.
- Treat `PROOF.md` as the theorem anchor.
- Treat generated runner outputs as implementation and audit evidence, not as
  theorem proof.
- Treat the May 16-17 gap-compatibility artifacts as measured branch evidence.
- Keep `factor_found = false` explicit wherever the bridge is not a factor
  recovery result.
