The Web Around A Semiprime

A semiprime is not isolated. The composites around it carry public traces of the distances to its two factors.

The center number is visible. Its two factors are hidden. The nearby composites are visible too, and they do not sit there as unrelated clutter. They form a local structure around the center number.

When the nearby composites are treated as a web, one factor distance can appear before any direct division of the semiprime is attempted.

The Usual Question

The conventional factoring question is direct: which number divides the semiprime? A proposed divisor is tested against the center number. If it divides cleanly, the factor has been found.

That direct question aims at the hidden factors themselves. The web method starts from a different public object: the surrounding composites.

The Neighborhood

Move one step left or right from the center number, and another number appears. Move again, and another appears. Many of those nearby numbers are composite. Each composite has small public features that can be read without knowing the hidden factors of the center.

The method uses those public features to draw threads. A thread is a repeated relationship that passes through more than one nearby position.

Intersections

A single thread is weak. It can point to many places. Several independent threads crossing the same distance are different. They create a nomination.

The nominated object is a distance from the center. It is not chosen because it was tested as a divisor. It is chosen because the surrounding web points toward it.

Anchor And Confirmation

The working shape is not forced symmetry. One side of the center can carry the stronger pattern. The other side only has to confirm the same distance.

The web is not equally strong on both sides of the center. A useful factor signal can be lopsided: one side anchors it, and the opposite side confirms it.

Local Distance Bands

A single global top list can hide the correct distance. Nearer positions produce many nominations, and those nominations can occupy the top of a global ranking. The hit can still be present, but buried inside its own distance scale.

Reading the web locally preserves the signal. Each distance scale gets its own nominations, so nearby structure does not erase a farther hit.

What Was Measured

Six semiprimes were tested. In all six cases, one factor distance appeared in the frozen public web nominations. The hidden factors entered only after the nominations were fixed, as a check against the output.
