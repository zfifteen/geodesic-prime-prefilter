Adaptive Support V2 Result

Finding: adaptive public windowing fixes the coverage failure on the tested continuation cases, and support-count ranking recovers the four toy cases, but the method still fails on the larger covered cases.

Public Contract

  • Radii are fixed public values: 256, 1024, 4096, 16384, 65536, 262144, 1048576, 2097152.
  • Threads remain 2, 3, 5.
  • Each offset is ranked by public support count, then proximity.
  • The private audit uses hidden factors only after public output is frozen.

Classification

Boundary measurement. The adaptive support selector is a real improvement over proximity-only on toy cases, but it does not scale across the first continuation cases. The larger factor offsets are covered by the public window, but their final full ranks are thousands to tens of thousands deep.

No RSA-scale factor-recovery claim follows from this experiment. The useful result is narrower: the failure is now primarily selector strength, not window coverage, for the tested continuation cases.
