# Terms Start Here

If the `GWR` essays or finding notes feel too jargon-heavy, start with:

- [GWR_glossary.md](./GWR_glossary.md)
- [../current_headline_results.md](../current_headline_results.md)
- [../../PROOF.md](../../PROOF.md)

That glossary explains the repo’s main terms in plain language before you go
back to the denser notes and essays. The headline results page and proof
summary are the status sources for what is proved, what is an exact corollary,
and what remains archived as historical framing. `PROOF.md` is definitive for
the prime-gap maximizer theorem.
