# Essay series

This folder holds essay drafts for PGS exposition and classical comparison.

Some drafts target platforms that do not support rendered math notation. Those
texts carry the explanation in ordinary language, with formulas written in
plain unicode when needed. HTML essays are self-contained for `file://` reading.
