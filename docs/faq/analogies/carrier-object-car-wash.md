# Why does the carrier object matter?

## Short Answer

The carrier object matters because the proof has to carry the thing being
explained. For prime gap structure, that thing is the exact divisor-count
structure of the integers.

## Source Order

```text
divisor counts -> zero-excess returns -> prime gap structure -> zeta compression -> RH language
```

## Common Mistake

The mistake is to walk into the compressed language without carrying the source
object. Then the explanation has arrived without the thing it was supposed to
explain.

## Full Answer

Imagine someone needs to wash a car at a car wash fifty meters away and is told
to walk there. Walking reaches the building, but it leaves the car behind. The
task was not to reach the building. The task was to bring the car to the place
where washing happens.

The same carrier-object mistake appears in RH discussions. If the discussion
walks straight into zeta language and leaves the integer structure behind, it
has arrived at the analytic site without the arithmetic object.

Prime gap structure carries the object:

- divisor counts on the integer line;
- exact prime returns at `tau(n)=2`;
- the same prime returns as zero-excess returns $E(n)=0$ for `n>1`;
- ordered composite interiors between consecutive primes;
- zeta compression that records the same source.

The question is not whether one can reach zeta language. The question is
whether the integer carrier object is still present when the analytic language
is read.
