# Why is an exhaustion demand the wrong objection?

## Short Answer

The source field is exact. Asking for a separate listing of every downstream
analytic appearance confuses the source with its compressed descriptions.

## Source Order

```text
divisor counts -> prime gap structure -> zeta compression -> RH language
```

## Common Mistake

The mistake is to demand that the source prove every possible compressed
description one by one before the source is accepted as the carrier object.

## Full Answer

The divisor-count field is defined on the integers. It places primes by
`tau(n)=2`, orders gap interiors, and supplies the data that zeta compression
records.

Once the carrier object is fixed, downstream analytic descriptions are readings
of that carrier. They still require careful translation, but they do not become
separate sources of arithmetic authority.

The demand for an unlimited list of downstream appearances shifts attention
away from the exact object. The real source-side question is whether the
divisor-count structure has been correctly identified, proved, and connected to
the analytic record. The FAQ answers from that order.

## Status

- proved theorem: local prime placement and interior ordering are proved from
  divisor counts.
- exact zeta compression: the bridge identifies the analytic record of the
  source.
- explanatory consequence: downstream readings do not outrank the carrier
  object.
