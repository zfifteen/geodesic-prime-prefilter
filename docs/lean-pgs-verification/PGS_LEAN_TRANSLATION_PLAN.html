1. Executive Summary

This document provides a granular, line-mapped, phased plan for translating the two core universal theorems and their supporting lemmas from PROOF.md into Lean 4.

Primary Targets

  1. Direct Deterministic Next-Prime Theorem (via exact tau-scan): q = min {n > p : tau(n) = 2}
  2. GWR / Leftmost Minimum-Divisor Maximizer Theorem: The first interior integer achieving the global minimum divisor count inside a prime gap is the unique maximizer of F(n) = −E(n).

The effort will produce a high-fidelity, machine-checked mirror while preserving full PGS-native framing, 1:1 traceability, and strict state separation (Proved / Measured / Audit / Hypothesis / Unresolved / Invalidated).

Phase 4 — Direct Deterministic Next-Prime Theorem (Core Theorem #1)

Target Statement 
theorem direct_deterministic_next_prime
    (p : Nat) (hp : Nat.Prime p) :
    ∃ q, Nat.Prime q ∧ q > p ∧ 
    (∀ m, p < m → m < q → tau m > 2) ∧

8. Risks & Mitigations Specific to This Translation

  • Risk: The finite base (220M gaps) is too large to reproduce inside Lean.
    Mitigation: Treat it as an Audit data artifact. The universal theorems do not depend on reproducing the entire table in Lean.
  • Risk: Classical lemmas (Bertrand, divisor bounds) leak into the PGS reasoning frame.
    Mitigation: Every such lemma must be imported into a clearly labeled "Classical Comparison Layer" module and never used to choose PGS outputs.
  • Risk: Square-branch bounded-compression obligation is accidentally promoted to a "proved" theorem.
    Mitigation: Strict status vocabulary enforcement in all comments and the HTML surface.
  • Risk: Proofs become elegant but lose 1:1 correspondence with the prose structure.
    Mitigation: Mandatory "References" header + periodic prose-vs-Lean diff reviews.
