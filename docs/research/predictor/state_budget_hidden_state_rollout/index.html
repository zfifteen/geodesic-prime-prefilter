State-Budget Probe: Plain-English Plan

Some prime gaps with the same obvious local description behave differently in the next gap. The difference is tied to how close the selected interior integer sits to the next prime-square boundary.

Plain English Finding

PGS already chooses a special composite number inside each prime gap. Call it w. The next prime at the right edge of the gap is q.

The probe asks one narrow question: after PGS chooses w, does it matter how much room remains before the next prime-square boundary? On the measured surface, yes. Rows with low budget use and rows with high budget use have different next-gap behavior.

What is being measured? The fraction of the distance from w to the next prime-square boundary that has already been used by the endpoint q.
Why care? If that fraction predicts the next gap, then the current gap is carrying a small amount of state into the next gap.
What is the claim? This is measured evidence for a transition variable, not a theorem yet.

The Mechanism

The useful picture is a ruler. Start at the selected integer w. End at the next prime-square boundary. Mark where the actual prime endpoint q lands on that ruler. The mark is the budget number.

Matched-Pair Ruler Test

The simpler memory test does not train a cutoff across powers. It compares rows that already match on the known current-gap facts. Inside each matched cell, target-next rows are paired against non-target-next rows. If the target-next row sits lower on the square ruler, that pair counts as a positive square-ruler win.

152 matched cells with both next outcomes
589 target versus non-target pairs
+73 signed square-ruler advantage
+70 signed tail-length control advantage

Plain readout: current gaps do show a positive within-cell ordering. Rows whose next gap returns to the target state usually sit lower on the current gap's ruler. But plain tail length almost reproduces the same effect. With a required control margin of 15 signed wins, the square-ruler-specific verdict is unresolved.

This is the sharper status: the current gap contains memory-like ordering, but the current retained surface does not yet prove that the prime-square boundary is the mechanism carrying that memory.

Acceptance Criteria

Promote

Promote if the budget split improves prediction on fresh windows and beats the control features.

Keep As Hypothesis

Keep as unresolved if it works on the current retained surface but does not hold cleanly on fresh windows.

Reject

Reject the memory-bit reading if shuffled labels match the signal, or if the fresh-window gain over the existing model is zero or negative.

Bottom Line

The pooled evidence says the selected integer has a measurable square-budget signal. The first strict held-out ruler test does not yet turn that signal into a promoted transition-state model. The matched-pair test finds a positive memory-like ordering, but tail length nearly ties the square ruler. The current finite status is sharper now: pooled signal measured, hard-gated held-out promotion not achieved, matched-pair ordering positive but square-specific mechanism unresolved.
