# Contributing to Prime Gap Structure

Please review `AGENTS.md` before contributing. All work is strictly regulated by the project's documentation standards.

## Reporting Issues
- Provide specific file paths and line numbers.
- Cite the relevant mathematical theorems where applicable.

## Submitting Pull Requests
- Follow the 4-phase authoring procedure as detailed in `AGENTS.md`.
- No en dashes or em dashes may be used in any documentation or code comments.
- Do not use redundant filenames in Markdown headers.
