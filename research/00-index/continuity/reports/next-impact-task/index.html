3. PGS-native frame for the task

Observable objects

  • Public modulus N.
  • floor(sqrt(N)) used only as orientation, not as a candidate chamber.
  • Previous public endpoint before that orientation point (chain start).
  • PGSPG reset certificates at successive public endpoints (anchor, reset endpoint, carrier, lock, tails, deadline, signature).
  • Floor-transported images of certificate coordinates through N.
  • Named residual when reciprocal GWR-carrier transport fails to close.

Ordinary-language mechanism

Walk the public endpoint chain. At each step, read the certificate of the current endpoint, transport selected certificate coordinates through the reciprocal floor map of N, and ask whether the opposite-side certificate and GWR-carrier fields close. When they do not, emit a residual code. The new work is to invent one public discriminator D built only from those certificate fields so that the 50-bit residual either closes under D, splits into a named subclass, or stays unresolved for a structural reason that 40-bit and 64-bit cases still pass.
