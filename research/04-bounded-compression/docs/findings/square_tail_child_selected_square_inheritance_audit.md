# Square-Tail Child Selected-Square Inheritance Audit

## Status

Audit evidence. Not a proof.

## Finding

Composite M-rough defects in the measured descent project to selected-square
child roots. That property is real, but it is not the missing transport law.

The same selected-square child status appears in the full-cutoff local CRT
singleton-carrier model. Therefore child selected-square status alone does not
separate actual PGS descent from an artificial local obstruction cover.

| Source | Child roots | Selected-square children | Not selected-square |
|---|---:|---:|---:|
| Standing record actual composite rough defects | `62` | `62` | `0` |
| Representative actual composite rough tail | `12` | `12` | `0` |
| Full-cutoff CRT model singleton carriers | `569` | `569` | `0` |

## Boundary

The observed inheritance remains useful as descent anatomy:

```text
composite M-rough parent row
-> least-factor child root
-> child selected-square state.
```

It does not eliminate a hypothetical parent obstruction word. A proof still
needs an ordered transport statement connecting parent obstruction rows to
child closure, or a direct exclusion of all-composite M-rough defects.
