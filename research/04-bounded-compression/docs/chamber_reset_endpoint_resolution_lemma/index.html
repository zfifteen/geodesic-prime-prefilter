Chamber-Reset Endpoint Resolution Lemma

Subsections: S1 endpoint identification · S2 band residual and chamber-prefix phase order · S3 right completion and chamber-reset residual · S4 interior τ4 field and chamber-cover residual · S5 quartile-balance residual on Tau4 · S6 late-trail dual markers

Lemma target: UNRESOLVED   Direct next-prime + Interior Maximizer: PROVED   d=4 SDA transfer: INVALIDATED

Plain object

Start at a known left prime p. Walk the ordered integers above p with the exact divisor-count field. The first integer with divisor count 2 is the right prime q. Inside the open gap, the leftmost integer with the smallest divisor count is the selected integer w.

On the selected-square branch, that selected integer is a prime square w = r2. The quantity that must be controlled is the backward distance from that square to the left endpoint: 

D(r) = r2 - p

Chamber reset names the restart of the search at the accepted right endpoint q. This subsection does not redefine chamber reset. It isolates the endpoint-distance obligation that appears when the selected witness inside the chamber is a prime square.

Subsection S1 — Selected-square endpoint identification

First constructive subsection (prior hour). It states hypotheses, the constructive claim under those hypotheses, and an explicit falsification command. It does not claim a proof of prime-square proximity. PROOF.md controls theorem status.

Hypotheses (H1–H4)

  1. H1 (consecutive primes). p < q are consecutive primes with nonempty interior I.
  2. H2 (selected-square branch). The GWR selected integer satisfies τ(w) = 3, so w = r2 for a unique prime root r, and r2 is the first prime square in I.
  3. H3 (selected-square characterization). If s is the prime immediately before r, then 
    s2 < p < r2.
    Equivalently, with P(r2) the greatest prime below r2, 
    s2 < P(r2) < r2
and p = P(r2).
  4. H4 (chamber prefix divisor floor). On the ordered chamber prefix {p+1, …, r2−1}, 
    min τ(n) = 4.
    In particular the first interior divisor count equal to 3 occurs exactly at offset D(r): 
    first_τ3_offset = D(r) = r2 − p.

Constructive claim under H1–H4

Claim S1 (endpoint identification; proved from H1–H4 and GWR).

Under H1–H4, the selected endpoint inside the gap is uniquely r2, the chamber prefix carries no earlier prime-square endpoint, and the backward distance from the selected square endpoint to the left prime is exactly 

D(r) = r2 − p = first_τ3_offset.

Therefore any bound on the selected-square branch reduces exactly to a bound on this single integer distance. No residue cover of a fixed finite offset list, and no d=4 Short-Divisor-Average transfer, is required for this identification step.

Unresolved distance target (not claimed proved here)

Target S1* (prime-square proximity on selected-square branch).

D(r) ≤ max(64, ceil(0.5 · log(r2)2)).

Status: UNRESOLVED as a universal theorem under the hypotheses of PROOF.md §Square-Branch Reduction. Claim S1 identifies the object; Target S1* is the remaining compression of that object to the dynamic logarithmic-square cutoff.

The deterministic band bound from H3, 

D(r) < r2 − s2 = (r − s)(r + s),

is available from the selected-square characterization, but does not imply Target S1*. That band is larger than the dynamic cutoff on the measured extremal rows and is not a substitute for proximity.

Subsection S2 — Band residual object and chamber-prefix phase order

Second constructive subsection (prior hour). Builds on Claim S1 only. It names the residual open set where Target S1* can still fail, and the ordered early-τ=4 / late-τ=3 phase structure forced by H4. It does not prove Target S1*. PROOF.md §Square-Branch Reduction controls: the prime-square proximity target remains unresolved.

Plain object

After left prime p, the chamber prefix is the ordered ruler {p+1, …, r2−1}. Under H4 that ruler never dips to divisor count 3; its floor is 4. The first divisor-count 3 lands exactly at the selected square, at distance D(r) (Claim S1). Separately, the selected-square characterization (H3) places p strictly above the previous prime square s2, so D(r) sits in a huge open band below r2 − s2. Target S1* asks for the much smaller dynamic cutoff on that same distance.

Hypotheses

Reuse H1–H4 from Subsection S1 without change. No new classical gates. No d=4 SDA hypothesis. No fixed-offset residue cover.

Constructive claim S2-A (chamber-prefix phase order)

Claim S2-A. Assume H1–H4 and D(r) ≥ 2.

Then the ordered chamber prefix admits a well-defined first offset with divisor count exactly 4, and that offset is strictly before the selected square endpoint: 

1 ≤ first_τ4_offset < first_τ3_offset = D(r).

Equivalently: every integer in {p+1, …, p + first_τ4_offset − 1} has τ ≥ 5 (empty if first_τ4_offset = 1), the integer at offset first_τ4_offset has τ = 4, and the first τ = 3 occurs only at offset D(r). This is the early-τ=4 / late-τ=3 phase order on the selected-square chamber.

Status: constructive from H4 + Claim S1 (ordered min-τ floor and first τ=3 endpoint identification). Not a bound on D(r).

Constructive claim S2-B (band residual object)

Claim S2-B. Assume H1–H3. Write

Band(r)  = (r − s)(r + s) = r2 − s2
C_dyn(r) = max(64, ceil(0.5 · log(r2)2)).

Then the selected-square characterization forces the strict band inequality 

D(r) < Band(r).

Define the open residual annulus (as a set of integer distances, not a geometric region in the plane): 

Annulus(r) = { k ∈ ℤ : C_dyn(r) < k < Band(r) }.

Under H1–H3, Target S1* fails at root r if and only if 

D(r) ∈ Annulus(r).

Equivalently, closing Target S1* is exactly the statement that the selected endpoint distance never enters Annulus(r). The band bound alone does not empty that annulus: on measured extremal rows Band(r) is many orders of magnitude larger than C_dyn(r).

Status: constructive identification of the residual open set. Target S1* remains UNRESOLVED.

Subsection S3 — Right-endpoint completion and chamber-reset residual

Third constructive subsection (this hour). Builds on Claims S1 and S2 only. It names the right completion after the selected square, the chamber-reset residual triple, and the late-dominant phase residual forced by S2-A. It does not prove Target S1*. PROOF.md §Square-Branch Reduction controls: the prime-square proximity target remains UNRESOLVED. Residual claims RC6–RC8 are attached as audit only and are not promoted to theorem status.

Plain object

Claim S1 places the selected square at backward distance D(r) = r2 − p. Claim S2-B names the residual open set Annulus(r) where Target S1* can still fail. The chamber is not finished at the square. The ordered divisor-count walk continues past r2 until the first integer with divisor count 2. That integer is the right prime q. Chamber reset accepts q and restarts the next search there. This subsection isolates that right completion and the residual state carried across the reset — without using that residual as a classical gate on D(r).

Hypotheses

Reuse H1–H4 from Subsection S1 without change. Add one completion hypothesis only:

  1. H5 (right completion after selected square). Under H1–H2, the ordered search after the selected square continues by exact divisor counts and stops at the first integer with τ = 2: 
    q = min{ n > r2 : τ(n) = 2 }.
    This is the direct next-prime rule applied after the selected square (already proved in PROOF.md); it is not a new primality oracle and not a Miller-Rabin or sieve gate.

Constructive claim S3-A (right-endpoint completion)

Claim S3-A. Assume H1–H2 and H5.

Define the forward residual after the selected square: 

F(r) = q − r2.

Then F(r) ≥ 1, the right endpoint of the chamber is exactly q = r2 + F(r), and the full gap length factors as 

q − p = D(r) + F(r).

Endpoint resolution on the selected-square branch therefore splits into a backward obligation D(r) and a forward residual F(r). Target S1* constrains only the backward obligation. Closing S1* does not require a bound on F(r); measuring F(r) does not substitute for a bound on D(r).

Status: constructive from the proved direct next-prime rule after the selected square plus Claim S1. Not a bound on D(r).

Constructive claim S3-B (chamber-reset residual triple)

Claim S3-B. Assume H1–H5 and Claim S2-A.

The selected-square chamber carries the residual triple 

ResetResidual(r) = ( D(r), F(r), first_τ4_offset ).

Chamber reset accepts the right endpoint q and restarts the next ordered search at q. The triple is the exact residual state of the completed selected-square chamber under the stated hypotheses:

  • D(r) is the selected-square endpoint distance (Claim S1);
  • F(r) is the forward residual to the accepted right prime (Claim S3-A);
  • first_τ4_offset is the early-τ=4 marker on the chamber prefix (Claim S2-A).

Under Claim S2-B, Target S1* fails at root r if and only if D(r) ∈ Annulus(r). The components F(r) and first_τ4_offset stratify residual audit surfaces; they are not classical inference gates and do not by themselves empty Annulus(r).

Status: constructive residual-state identification. Target S1* remains UNRESOLVED.

Constructive claim S3-C (late-dominant phase residual)

Claim S3-C. Assume H1–H4, Claim S2-A, and D(r) ≥ 2.

Define the late-dominant phase residual 

phase_gap(r) = (D(r) − first_τ4_offset) / D(r).

Then 

0 < phase_gap(r) < 1,
first_τ4_offset = D(r) · (1 − phase_gap(r)),
1 ≤ first_τ4_offset ≤ D(r) − 1.

Equivalently, the early-τ=4 marker occupies a strict proper prefix of the chamber, and the selected-square endpoint occupies the complementary late fraction phase_gap(r) of the backward distance. This is the ordered phase residual of Claim S2-A written as a single chamber invariant.

Status: constructive rewrite of S2-A. It does not imply D(r) ≤ C_dyn(r) and does not empty Annulus(r).

Subsection S4 — Interior τ4 field and chamber-cover residual

Fourth constructive subsection (this hour). Builds on Claims S1–S3 only. It names the full ordered τ4 offset set on the chamber prefix, three cover residual functionals on that set, and the extended chamber-reset residual that carries those functionals across the accepted right endpoint. It does not prove Target S1*. PROOF.md §Square-Branch Reduction controls: the prime-square proximity target remains UNRESOLVED. Residual claims RC9–RC11 are attached as audit only and are not promoted to theorem status.

Plain object

Claims S1–S3 identify the selected-square distance D(r), the residual open set Annulus(r), the forward residual F(r), and the early marker first_τ4_offset. The chamber prefix is not exhausted by that first τ4 marker. On the ordered ruler {p+1, …, r2−1} the divisor-count field places many integers with τ = 4 before the late selected endpoint with τ = 3. This subsection names that full ordered set and the cover residuals it forces — without using them as classical gates on D(r) and without claiming that they empty Annulus(r).

Hypotheses

Reuse H1–H5 from Subsections S1 and S3 without change. Add one field hypothesis only:

  1. H6 (interior τ4 field nonempty under H4). Under H1–H4 and D(r) ≥ 2, the chamber prefix contains at least one integer with divisor count 4. Equivalently, the ordered offset set defined in Claim S4-A is nonempty. This is the field-level reading of H4 (chamber floor 4 with late first τ = 3 at offset D(r)); it does not assert any density law.

Constructive claim S4-A (interior τ4 field)

Claim S4-A. Assume H1–H4, H6, and D(r) ≥ 2.

Define the ordered interior τ4 field 

Tau4(r) = { k ∈ {1, …, D(r)−1} : τ(p + k) = 4 },
ordered by increasing k.

Write 

first_τ4_offset = min Tau4(r),
last_τ4_offset  = max Tau4(r),
|Tau4(r)|       = cardinality of Tau4(r).

Then Tau4(r) is a nonempty finite increasing sequence in the open chamber prefix, 1 ≤ first_τ4_offset ≤ last_τ4_offset ≤ D(r)−1, and Claim S2-A is exactly the statement first_τ4_offset < D(r) with late selected endpoint τ(p + D(r)) = 3. The field is a pure divisor-count object on the ordered gap state. It is not a residue cover, not a product check, and not a sieve.

Status: constructive from H4 / H6 and Claim S1. Not a bound on D(r).

Constructive claim S4-B (chamber-cover residual functionals)

Claim S4-B. Assume H1–H6 and Claim S4-A.

From the ordered field Tau4(r) define three cover residual functionals: 

early_half_mass(r) = |{ k ∈ Tau4(r) : k ≤ ⌊D(r)/2⌋ }| / |Tau4(r)|,

late_span(r)       = last_τ4_offset / D(r),

max_gap_frac(r)    = max_gap(r) / D(r),

where max_gap(r) is the largest consecutive gap among the ordered markers 

0 < first_τ4_offset < ⋯ < last_τ4_offset < D(r)

including the lead gap before the first τ4 and the trail gap after the last τ4 up to the selected-square endpoint. Then 

0 < early_half_mass(r) ≤ 1,
0 < late_span(r) < 1,
0 < max_gap_frac(r) < 1.

These three numbers are exact chamber-cover residuals of the divisor-count field under H1–H6. Together they say whether τ4 mass is early-concentrated, whether τ4 reaches the late prefix, and whether the chamber admits a large τ4 desert before the late τ=3 endpoint.

Status: constructive definitions on Tau4(r). They do not imply D(r) ≤ C_dyn(r) and do not empty Annulus(r).

Constructive claim S4-C (extended chamber-reset residual)

Claim S4-C. Assume H1–H6 and Claims S3-B, S4-A, S4-B.

Extend the chamber-reset residual of Claim S3-B by the cover package: 

Cover(r) = ( early_half_mass(r), late_span(r), max_gap_frac(r) ),

ResetResidual⁺(r) = ( D(r), F(r), first_τ4_offset, Cover(r) ).

Chamber reset still accepts the right endpoint q = r2 + F(r) and restarts the next ordered search at q. The extended residual is the exact selected-square chamber state under the stated hypotheses once the full τ4 field is admitted:

  • D(r) is the selected-square endpoint distance (Claim S1);
  • F(r) is the forward residual (Claim S3-A);
  • first_τ4_offset is the early marker (Claim S2-A / S3-B);
  • Cover(r) is the ordered-field cover residual (Claim S4-B).

Under Claim S2-B, Target S1* fails at root r if and only if D(r) ∈ Annulus(r). The cover package stratifies residual audit surfaces on completed chambers; it is not a classical inference gate and does not by itself force D(r) ∉ Annulus(r).

Status: constructive residual-state identification. Target S1* remains UNRESOLVED.

Subsection S5 — Quartile-balance residual on the interior τ4 field

Fifth constructive subsection (this hour). Builds on Claims S1–S4 only. It partitions the ordered field Tau4(r) into chamber quarters, names three quartile-balance residual functionals finer than the half-mass cover of Claim S4-B, and extends the chamber-reset residual by that balance package. It does not prove Target S1*. PROOF.md §Square-Branch Reduction controls: the prime-square proximity target remains UNRESOLVED. Residual claims RC12–RC14 are attached as audit only and are not promoted to theorem status.

Plain object

Claim S4-A names the full ordered τ4 offset set on the chamber prefix. Claim S4-B records whether that mass is early-concentrated (half-scale), whether it reaches the late prefix, and whether a large τ4 desert appears. Those three numbers do not resolve whether both outer quarters of the chamber carry τ4 mass, or where the median τ4 offset sits relative to D(r). This subsection names that finer ordered geometry — still a pure divisor-count residual on the selected-square chamber, still not a classical gate on D(r), and still not a proof that Annulus(r) is empty.

Hypotheses

Reuse H1–H6 from Subsections S1, S3, and S4 without change. No new hypothesis is introduced. The quartile partition is defined on the same nonempty field Tau4(r) forced by H6.

Constructive claim S5-A (quartile partition of Tau4)

Claim S5-A. Assume H1–H6 and Claim S4-A, with D(r) ≥ 4.

Write the ordered field Tau4(r) = {k1 < ⋯ < km} with m = |Tau4(r)| ≥ 1. Define the chamber quarter cuts 

Q1(r) = ⌊D(r)/4⌋,
Q3(r) = ⌊3·D(r)/4⌋.

Partition the field into three ordered residual zones (outer early, mid-band, outer late): 

Tau4_Q1(r)  = { k ∈ Tau4(r) : k ≤ Q1(r) },
Tau4_mid(r) = { k ∈ Tau4(r) : Q1(r) < k ≤ Q3(r) },
Tau4_Q4(r)  = { k ∈ Tau4(r) : k > Q3(r) }.

These three sets are pairwise disjoint and their union is Tau4(r). The partition is exact on the ordered chamber prefix under H1–H6. It does not assert that every zone is nonempty, and it does not assert a density law.

Status: constructive partition of Claim S4-A. Not a bound on D(r).

Constructive claim S5-B (quartile-balance residual functionals)

Claim S5-B. Assume H1–H6 and Claims S4-A, S5-A.

From the ordered partition define three quartile-balance residual functionals: 

first_quarter_mass(r) = |Tau4_Q1(r)|  / |Tau4(r)|,

last_quarter_mass(r)  = |Tau4_Q4(r)|  / |Tau4(r)|,

median_frac(r)        = median(Tau4(r)) / D(r),

where median(Tau4(r)) is the ordinary median of the ordered offset list (for even cardinality, the mean of the two central offsets). Then 

0 ≤ first_quarter_mass(r) ≤ 1,
0 ≤ last_quarter_mass(r)  ≤ 1,
0 < median_frac(r) < 1,
first_quarter_mass(r) + last_quarter_mass(r) ≤ 1.

Relation to Claim S4-B: early-half mass is a coarser half-scale residual; first-quarter mass is the outer-early refinement. Late-span records only whether the last τ4 reaches near D(r); last-quarter mass records how much of the field occupies the outer-late quarter. The median fraction places the center of the ordered field on the chamber ruler. Together they say whether the selected-square chamber is a balanced scattered τ4 field under the hard late τ=3 endpoint, without using classical product, gcd, or primality gates.

Status: constructive definitions on Tau4(r). They do not imply D(r) ≤ C_dyn(r) and do not empty Annulus(r).

Constructive claim S6-A (last-τ4 marker and late trail)

Claim S6-A. Assume H1–H6 and Claim S4-A, with D(r) ≥ 2.

From the ordered field Tau4(r) define

trail_gap(r)   = D(r) − last_τ4_offset.

1 ≤ first_τ4_offset ≤ last_τ4_offset ≤ D(r) − 1,
1 ≤ trail_gap(r) ≤ D(r) − first_τ4_offset.

Equivalently: every integer on the open trail {p + last_τ4_offset + 1, …, p + D(r) − 1} has τ ≠ 4 and, by H4, τ ≥ 4, so in fact τ ≥ 5 on that open trail (empty only if trail_gap(r) = 1, in which case the last τ4 sits immediately before the selected square). The selected-square endpoint remains the first interior integer with τ = 3 at offset D(r) (Claim S1). The late trail is therefore the exact ordered residual between last τ4 support and the late τ=3 endpoint.
