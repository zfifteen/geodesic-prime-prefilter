Plain object

Start at a known left prime p. Walk the ordered integers above p with the exact divisor-count field. The first integer with divisor count 2 is the right prime q. Inside the open gap, the leftmost integer with the smallest divisor count is the selected integer w.

On the selected-square branch, that selected integer is a prime square w = r2. The quantity that must be controlled is the backward distance from that square to the left endpoint: 

D(r) = r2 - p

Chamber reset names the restart of the search at the accepted right endpoint q. This subsection does not redefine chamber reset. It isolates the endpoint-distance obligation that appears when the selected witness inside the chamber is a prime square.

Hypotheses (H1–H4)

  1. H1 (consecutive primes). p < q are consecutive primes with nonempty interior I.
  2. H2 (selected-square branch). The GWR selected integer satisfies τ(w) = 3, so w = r2 for a unique prime root r, and r2 is the first prime square in I.
  3. H3 (selected-square characterization). If s is the prime immediately before r, then 
    s2 < p < r2.
    Equivalently, with P(r2) the greatest prime below r2, 
    s2 < P(r2) < r2
and p = P(r2).
  4. H4 (chamber prefix divisor floor). On the ordered chamber prefix {p+1, …, r2−1}, 
    min τ(n) = 4.
    In particular the first interior divisor count equal to 3 occurs exactly at offset D(r): 
    first_τ3_offset = D(r) = r2 − p.

Constructive claim under H1–H4

Claim S1 (endpoint identification; proved from H1–H4 and GWR).

Under H1–H4, the selected endpoint inside the gap is uniquely r2, the chamber prefix carries no earlier prime-square endpoint, and the backward distance from the selected square endpoint to the left prime is exactly 

D(r) = r2 − p = first_τ3_offset.

Therefore any bound on the selected-square branch reduces exactly to a bound on this single integer distance. No residue cover of a fixed finite offset list, and no d=4 Short-Divisor-Average transfer, is required for this identification step.

Subsection S2 — Band residual object and chamber-prefix phase order

Second constructive subsection (prior hour). Builds on Claim S1 only. It names the residual open set where Target S1* can still fail, and the ordered early-τ=4 / late-τ=3 phase structure forced by H4. It does not prove Target S1*. Plain object

After left prime p, the chamber prefix is the ordered ruler {p+1, …, r2−1}. Under H4 that ruler never dips to divisor count 3; its floor is 4. The first divisor-count 3 lands exactly at the selected square, at distance D(r) (Claim S1). Separately, the selected-square characterization (H3) places p strictly above the previous prime square s2, so D(r) sits in a huge open band below r2 − s2. Target S1* asks for the much smaller dynamic cutoff on that same distance.

Hypotheses

Reuse H1–H4 from Subsection S1 without change. No new classical gates. No d=4 SDA hypothesis. No fixed-offset residue cover.

Constructive claim S2-A (chamber-prefix phase order)

Claim S2-A. Assume H1–H4 and D(r) ≥ 2.

Then the ordered chamber prefix admits a well-defined first offset with divisor count exactly 4, and that offset is strictly before the selected square endpoint: 

1 ≤ first_τ4_offset < first_τ3_offset = D(r).

Equivalently: every integer in {p+1, …, p + first_τ4_offset − 1} has τ ≥ 5 (empty if first_τ4_offset = 1), the integer at offset first_τ4_offset has τ = 4, and the first τ = 3 occurs only at offset D(r). This is the early-τ=4 / late-τ=3 phase order on the selected-square chamber.

Status: constructive from H4 + Claim S1 (ordered min-τ floor and first τ=3 endpoint identification). Not a bound on D(r).

Constructive claim S2-B (band residual object)

Claim S2-B. Assume H1–H3. Write

Band(r)  = (r − s)(r + s) = r2 − s2
C_dyn(r) = max(64, ceil(0.5 · log(r2)2)).

Then the selected-square characterization forces the strict band inequality 

D(r) < Band(r).

Define the open residual annulus (as a set of integer distances, not a geometric region in the plane): 

Annulus(r) = { k ∈ ℤ : C_dyn(r) < k < Band(r) }.

Under H1–H3, Target S1* fails at root r if and only if 

D(r) ∈ Annulus(r).

Equivalently, closing Target S1* is exactly the statement that the selected endpoint distance never enters Annulus(r). The band bound alone does not empty that annulus: on measured extremal rows Band(r) is many orders of magnitude larger than C_dyn(r).

Status: constructive identification of the residual open set. Target S1* remains UNRESOLVED.

Constructive claim S4-A (interior τ4 field)

Claim S4-A. Assume H1–H4, H6, and D(r) ≥ 2.

Define the ordered interior τ4 field 

Tau4(r) = { k ∈ {1, …, D(r)−1} : τ(p + k) = 4 },

Write 

first_τ4_offset = min Tau4(r),
last_τ4_offset  = max Tau4(r),
|Tau4(r)|       = cardinality of Tau4(r).

Then Tau4(r) is a nonempty finite increasing sequence in the open chamber prefix, 1 ≤ first_τ4_offset ≤ last_τ4_offset ≤ D(r)−1, and Claim S2-A is exactly the statement first_τ4_offset < D(r) with late selected endpoint τ(p + D(r)) = 3. The field is a pure divisor-count object on the ordered gap state. It is not a residue cover, not a product check, and not a sieve.

Status: constructive from H4 / H6 and Claim S1. Not a bound on D(r).

Constructive claim S4-B (chamber-cover residual functionals)

Claim S4-B. Assume H1–H6 and Claim S4-A.

From the ordered field Tau4(r) define three cover residual functionals: 

early_half_mass(r) = |{ k ∈ Tau4(r) : k ≤ ⌊D(r)/2⌋ }| / |Tau4(r)|,

late_span(r)       = last_τ4_offset / D(r),

max_gap_frac(r)    = max_gap(r) / D(r),

where max_gap(r) is the largest consecutive gap among the ordered markers 

0 < first_τ4_offset < ⋯ < last_τ4_offset < D(r)

including the lead gap before the first τ4 and the trail gap after the last τ4 up to the selected-square endpoint. Then 

0 < early_half_mass(r) ≤ 1,
0 < late_span(r) < 1,
0 < max_gap_frac(r) < 1.

These three numbers are exact chamber-cover residuals of the divisor-count field under H1–H6. Together they say whether τ4 mass is early-concentrated, whether τ4 reaches the late prefix, and whether the chamber admits a large τ4 desert before the late τ=3 endpoint.
