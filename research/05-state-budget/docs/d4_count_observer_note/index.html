The Simple Memory Signal Inside Prime Gaps

A long-running PGS test found a measured carrier of gap-to-gap memory. The carrier is not an exotic outside ruler. It is the number of d=4 positions inside the current prime-gap chamber.

Strongest supported finding

On the deterministic retained 8192-row-per-power 10^12..10^18 surface, d4_count is a measured PGS-native ordering carrier for the next triad state after current chamber facts, endpoint residue modulo 30, exact previous gap width, and endpoint tail are controlled.

Start With A Prime Gap

Take two neighboring primes. The whole-number space between them is a prime gap. Every number inside the gap is composite.

PGS treats that gap as a chamber with internal structure. Each interior number has a divisor count. A number with divisor count 4 has exactly four positive divisors. The new carrier simply counts how many such positions occur inside the current chamber.

Why This Is Significant

The first question was whether a prime gap carries any state into the next gap. The new result says the current chamber's internal d=4 population carries measured ordering information about the next triad state.

That moves the research away from an external ruler and back into the chamber's own divisor-count field. The chamber remembers through its population structure.
