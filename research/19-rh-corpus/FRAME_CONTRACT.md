# RH Branch Frame Contract (Hard Rule)

**Status:** binding program requirement, not a preference  
**Authority:** this file plus [START_HERE.md](./START_HERE.md), [SOURCE_STACK.md](./SOURCE_STACK.md), repo root `AGENTS.md`, [docs/rh/source-order.md](../../docs/rh/source-order.md)  
**Date locked:** 2026-07-11

---

## The rule

```text
PGS objects and laws are upstream.
Zeta compression is a reading of those objects.
RH is a downstream sentence about that reading after continuation.
```

**RH is never upstream of PGS.**

Any work that starts from zeros, poles, the critical line, explicit-formula
zero terms, or “how to prove RH,” and then searches for PGS objects that fit,
is **frame-wrong**. It is not an alternate research style. It is a contract
violation.

---

## Required order (only legal order)

```text
divisor counts / chambers / GWR / budgets / endpoint clocks
  → PGS local theorems (PROOF.md)
  → DNI coordinates and exact compression to ζ² and R = −ζ′/ζ
  → optional summatory source laws still stated without zeros
  → only then: source-to-spectral transfer, if a real source law forces it
  → only then: pole placement / RH sentence, if transfer closes
```

Nothing may reverse this arrow.

---

## Kill criteria (stop immediately)

Reject or rewrite any draft, experiment, prompt, or claim that:

1. **Driver test fails:** the primary question is RH, pole locus, or zero sums
   rather than a source law about \(\tau\), \(E\), \(H\), chambers, or endpoints.
2. **Statement test fails:** the claim cannot be stated without zeros, poles,
   \(\Lambda\), \(\psi\), or the critical line in the *statement* (downstream
   translation pages may use those words only as labeled reading).
3. **Worth-without-RH test fails:** the work would be discarded if RH were
   false; then it was never a source investigation.
4. **Rhyme test fails:** shared numerals or metaphors (especially \(1/2\)) are
   used as if they identified chamber geometry with \(\operatorname{Re}(s)=\tfrac12\).
5. **Support test fails:** bulk chamber loads are multiplied by interior
   \(\Lambda\) masks so that spectral language can “see” GWR (design-invalid
   under measured support mismatch; see RH-035 draft notes).

## Acceptance tests for new RH-corpus rows

Before adding or promoting any `RH-###` row:

1. **Upstream statement** exists (or the row is explicitly `unresolved` /
   `narrative` / `archived` downstream catalog).
2. **Boundary** column states what is *not* proved, including “not RH” when
   relevant.
3. **Driver** is a PGS object or law, not the RH sentence.
4. No en-dash-free prose may imply RH is proved by compression, budget, or
   half-scale rhyme.

## One-line rule for agents and humans

**Do not ask how PGS can serve RH. Ask which PGS laws are true. Only if a law
forces a reading of continued \(R\) may RH appear, and only as that reading.**
