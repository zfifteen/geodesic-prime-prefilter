Chamber-Tension Closure Hypothesis

Status: Hypothesis (split weak / strong)   Date: 2026-06-19   Plan: implementation_plan_2026-06.html   Proof target: weak_lfcl_proof_target.html   Authority: PROOF.md controls proved theorem status

Plain Opening

Start at a known prime p. Read the integers to its right one by one. Each composite before the next prime sits above a floor where primes have zero excess. That ordered lift inside the gap is not empty noise. It is a loaded chamber whose interior accumulates excess and whose right edge must reset to zero excess at the successor prime q.

The live research question is now split. Weak chamber-tension closure asks whether full traversal to a sufficient bound forces a unique reset at q, with τ(q)=2 as an audit signature. Strong closure asked whether prefix geometry alone names q before arrival without divisor-count selection — that path is now measured and largely closed.

Formal Hypothesis

Hypothesis HCTC-weak (live form).

Let p be a known prime and let the successor chamber be the ordered interval traversed from p+1 forward until chamber reset. The ordered excess field inside that chamber, together with the GWR landmark, the NLSC ceiling, and the chamber-reset geometry of the production selection rule, carries enough deterministic constraint that the successor endpoint q is the unique chamber-reset point.

Under HCTC-weak, the identity τ(q)=2 is the zero-excess signature of reset. It is used for audit and verification after chamber-reset geometry has emitted q. The live proof target is equivalence at sufficient bound, not early prefix prediction.

HCTC-strong (retired as default). Prefix geometry alone names q before arrival without τ≤2 selection. Measured falsification: unique NLSC-admissible composite law L2; see prefix-state-lfcl-decisive-2026-06/FINDINGS.md.

  -> zero-excess E(n) and budget B(I)

Forward Closure Law (Active Proof Target — Weak Form)

HCTC-weak becomes a theorem layer when the following sufficient-bound law is proved. Strong early-closure LFCL is no longer the default target.

Target law LFCL-weak (Sufficient-Bound Chamber Closure).

Fix a known prime p and a finite search bound sufficient for the production surface. Define the PGS chamber state after traversing a prefix of the search interval:

State(p, prefix) = (
  GWR lock or unresolved landmark status,
  NLSC ceiling T_<(w) when w is locked,
  lower-divisor threat bound,
  wheel-open candidate hypotheses,
  search-interval reset classification
)

There exists a deterministic endpoint functional

q = Closure(p, State)

such that:

  1. Closure(p, State) is computed without selecting the first integer with τ(n)=2 as the inference rule.
  2. Closure(p, State) equals the proved next prime min{n>p : τ(n)=2} on every input in the stated hypothesis class.
  3. τ(q)=2 is an audit identity checked after q is emitted.

Compact production form already recorded in the generator spec: q = B(p, S, w, τ(w)), where S is exact divisor-count search-interval state. LFCL asks for a theorem that this state functional is equivalent to the direct τ-scan rule with τ=2 removed from the selector role.

Falsification Criteria

HCTC is falsified if any of the following occur on a stated test surface:

  • A gap where chamber invariants computed from a valid prefix determine a candidate r ≠ q, with q the proved next prime.
  • A regime where B(I), GWR fractional position, NLSC ceiling, or reset geometry alone do not single out the endpoint before τ=2 is consulted in the selector.
  • A claimed chamber-closure path that requires hidden τ=2 scan, classical primality test, or fallback search to choose q, while presenting HCTC as resolved.
  • Any generator branch that treats audit confirmation as if it were the inference mechanism, or collapses hypothesis into theorem language.

Support Criteria

HCTC moves toward theorem layer only if:

  • Equivalence theorem: Rule X / search-interval-reset closure is proved equivalent to q = min{n>p : τ(n)=2}, with τ=2 entering only in audit.
  • Forward NLSC + GWR theorem: partial traversal from p until GWR lock and NLSC ceiling force a unique reset index q without τ=2 selection.
  • Implementation audit: production generator source is shown to compute q solely through the proved forward law, and measured surfaces match the proved rule on exact test regimes.

Minimal Decisive Experiment

The smallest falsification probe for HCTC is a pinned check-for-signal run over consecutive gaps up to a declared bound N:

  1. For each consecutive pair (p, q) with q known only from the proved τ-scan reference used as experiment ground truth, not as the tested selector.
  2. Traverse the search interval left to right, maintaining chamber state: running excess, GWR lock time, NLSC ceiling, threat flags, reset classification.
  3. At the earliest index where LFCL would declare forced closure, record candidate r.
  4. Compare r to reference q.
OutcomeInterpretation
r = q for every gap in the regime Support for HCTC on that regime; proceed to proof attempt of LFCL
Any r ≠ q HCTC falsified on that regime, or the state functional is incomplete
Closure index undefined before reaching reference q Forward law unresolved; chamber state insufficient as predictor

Experiment code must live in an isolated folder under experiments/. It must label the reference q lane as audit/ground truth, separate from the tested forward selector.

What This Hypothesis Does Not Claim

  • It does not downgrade the proved direct next-prime theorem in PROOF.md.
  • It does not replace GWR or NLSC with statistical, heuristic, or probabilistic language.
  • It does not claim RH, PNT, or zeta consequences from chamber budget alone.
  • It does not assert that the current v1.1 generator already satisfies LFCL; implementation validation and forward closure proof are separate statuses.
  • It does not treat measured B(I) linear scaling as a proof of prediction without τ=2.

Canonical Wording

Use this sentence in research notes, experiment specs, and continuity handoffs:

Hypothesis HCTC: The ordered excess field inside a prime-gap chamber carries enough deterministic constraint (GWR landmark, NLSC ceiling, excess budget, reset geometry) that the successor prime q is the unique chamber-reset point. Divisor count τ=2 is the zero-excess signature of that reset, usable for verification; it need not be the inference mechanism that determines q from p.
