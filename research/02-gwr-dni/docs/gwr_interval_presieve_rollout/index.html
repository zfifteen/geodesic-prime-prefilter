Contract Preserved

The optimization is a divisor-field computation improvement. It is not a new PGS rule, not a residue-class shortcut, and not a fallback path. The future implementation must preserve the ordered GWR scan.

Mechanism Map

Current scalar capped path

Each candidate offset asks the capped divisor routine to rediscover the small-factor structure of q + offset.

1Read one offset.
2Trial small primes for that integer.
3Classify the residual and update lex-min state.
4Repeat for the next offset until boundary.
->

Exact interval pre-sieve path

The chamber is stripped once through floor(cuberoot(q + C(q))), then the same ordered scan consumes localized divisor-field state.

1Pre-sieve [q + 1, q + C(q)].
2Store partial tau products and residual cofactors.
3Classify residuals only when needed for exact state.
4Stop at the same first tau(n) = 2 boundary.
