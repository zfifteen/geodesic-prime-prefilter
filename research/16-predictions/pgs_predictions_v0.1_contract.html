The Meaning of "Predictions" in This Program

Observable object: After a known prime p, the finite ordered sequence of integers p+1, p+2, …, q−1 (where q is the next prime) carries a complete divisor-count field τ(n). The integer w is defined exactly as the leftmost position in this interval that achieves the global minimum τ value inside the interval.

PGS-native definition of a Prediction: A deterministic rule or measurable carrier law, built only from already-proved or explicitly measured PGS objects (divisor-count field, DNI coordinate E(n), GWR leftmost-minimizer w, endpoint chains, modulus links, chamber-reset signatures, reciprocal transport), that from the current chamber state (or a short, fully determined preceding window) either:

  • resolves one or more future PGS states exactly (position of next w, next gap type after w, next chamber-reset signature, next modulus-link residual, etc.), or
  • returns an explicit unresolved state when the carrier does not decide.

Strictly forbidden in this track: probabilistic language ("with high probability", "~ c log log x", "likely"), classical analytic first framing (li(x), Cramér model, explicit formula remainders as the target, RH-conditional bounds as the payoff), or any mechanism that uses candidate testing, primality APIs, or product closure to choose the predicted state.

Proved Foundation (PROOF.md)

Selected Integer / Gap Winner w

Given prime p and next prime q returned by the deterministic divisor-count traversal, let I = {p+1, …, q−1} (nonempty). Define

w = min { n ∈ I : τ(n) = min_{m ∈ I} τ(m) }

The Interior Maximizer Theorem (PROOF.md) proves w is the unique integer in I that maximizes F(n) = −E(n) (equivalently, minimizes excess E(n)).

No-Later-Simpler-Composite (exact corollary)

Once w has appeared, no later integer in the same interior has strictly smaller τ. This is proved; it has been stress-tested on the full surface through 10^18 with zero violations (docs/RESULTS.md).

Existing Measured Carrier (Strongest Precedent)

The d4_count ordering carrier (research/05-state-budget, long-running 8192-row-per-power retained surface 10^12..10^18) is the cleanest existing example of PGS-native "prediction":

  • From the current chamber's divisor-count field (specifically the count of d(n)=4 positions), under the match mode mod30_prev_gap_exact, one obtains a measurable ordering advantage for the next triad state.
  • Verdict on that surface: ordering_carrier_found (decisive pairs 7881, edge +69 over endpoint-tail control, 6/7 positive held-out folds).
  • It remains measured, not promoted to theorem. It returns no probabilistic claim; it returns a carrier strength on an exact retained surface.

This is the correct shape for everything that will live in the Predictions track.

The Four Families. Translated into PGS-Native Terms

Family 1. Selected Composite (w) Positioning

Native statement: In the ordered divisor-count field of the gap after p, the offset w − p is a deterministic function of the local structure visible before or at the first d(n)=4 arrival (under square exclusion) plus any active chamber-reset or modulus-link signature carried from the previous gap.

Current status: The generator already computes carrier_w (or equivalent) as part of chamber-reset state. The task is to turn the existing computation into an explicit, falsifiable carrier law: "given current-chamber d4_count + square-phase flag + previous-gap tail length (under fixed match), the next w offset lies in a stated small integer set, or the carrier returns unresolved."

Falsification surface: Retained high-window catalogs (already generated in ch05). Measure exact hit rate of the carrier rule; record unresolved rate; do not use "high probability".

Family 2. Excess-Bounded Gap Closure

Native statement: The cumulative excess Σ E(n) (or max local E) from the leftmost min-d arrival w onward, combined with the square-phase terminal behavior and any active chamber-reset lock, forces the next return to E=0 (i.e., the next prime) before a deterministic threshold derived only from the divisor-field invariants already proved for that chamber type.

Current status: The proved No-Later-Simpler-Composite already gives one exact closure. The open question is whether stronger, type-specific closure bounds (in terms of current d4_count, square-phase presence, or modulus-link residual) can be stated and falsified on large exact surfaces.

Warning: Any claim of the form "G(x) = O(log x · …)" is a classical analytic statement. It may be a downstream consequence, but it is not the form of a PGS Prediction. PGS Predictions stay at the level of exact integer offsets or small finite sets of possible next states on concrete surfaces.

Family 3. E-fluctuation and Prime-Counting Error

Native statement (PGS side only): The cumulative excess integral (or discrete sum) across successive chambers, when tracked via the same carrier mechanisms used for next-triad ordering, produces a deterministic modulation of the local density of zero-excess returns. This modulation is measurable on retained windows as a structured deviation from uniform random placement of the next w and next prime.

Downstream reading (strictly after PGS source): The H(n) = log n + E(n) coordinate (docs/rh/) then supplies the exact compression that turns this integer-level modulation into the source term for the explicit formula. The PGS track itself does not derive or test bounds on |π(x) − li(x)|; it supplies the precise arithmetic input that the compression layer then reads.

The pasted feedback inverts the source order. The integer-level carrier law comes first; any statement about zeta zeros or the error term is a consequence read through the DNI-to-zeta bridge, never the reasoning engine.

Family 4. Special-Form Primes (Mersenne, twins, exponent walls)

Native statement: For candidates of special form (e.g., 2^p − 1 after a safe prime or Sophie-Germain pair, or exponents near known walls), the gap structure immediately preceding the candidate is an instance of the ordinary ordered prime-gap chamber. The same GWR-selected w and any active chamber-reset or modulus-link signature therefore supply the same deterministic constraints on the next zero-excess return as in the generic case.

Status: research/09-exponents/ already contains PGS experiments on exponent walls. The Predictions track can host the unification: treat the special-form case as just another chamber type whose carrier signature (previous d4_count, reset state, square phase) is measured on the same retained surfaces used for generic gaps.

Recommended First Pick (Minimal Executable Path)

Family 1 (w-position carrier) + the existing d4_count precedent.

Reason: The generator already emits the selected integer position. Chapter 05 already has the retained-surface machinery, the match-mode discipline, the held-out fold protocol, and the exact "ordering_carrier_found / does_not / unresolved" verdict language. Extending that exact protocol to the w offset (instead of next-triad gap type) is the smallest step that produces a new, publishable, fully auditable carrier surface this weekend.

Everything else (stronger gap-closure rules, E-fluctuation modulation, special-form unification) can be added later as additional carrier families using the same measurement contract.

Current State. Five Continuity Questions

1. Strongest supported claim
The meaning of "Predictions" for this program is deterministic carrier laws and structural resolution rules operating on PGS-native objects (divisor-count field, GWR w, chamber resets, modulus links). The strongest existing example is the d4_count ordering carrier on the 8192-row 10^12..10^18 surface (ordering_carrier_found).
