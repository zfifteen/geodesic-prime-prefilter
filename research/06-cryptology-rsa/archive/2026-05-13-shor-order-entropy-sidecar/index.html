What Changed

Shor's algorithm uses quantum phase estimation to recover order information. The probe shows that when PGS publicly resolves the reciprocal endpoint class, the corresponding order-denominator structure is already determined for that case.

The 40-bit rung does not need quantum order discovery in the measured sidecar because PGS supplies the endpoint class, the endpoint class supplies the candidate lambda structure, and the downstream audit verifies that the fixed-base order vector matches the true order vector.

What The Probe Actually Measures

The public side reads N, runs the existing reciprocal PGS certificate-pair surface, and records whether a public endpoint class exists before Shor order finding.

The audit side reads separate factor rows only after public inference. It computes the true lambda value, computes fixed-base order vectors for bases 2, 3, 5, 7, 11, 13, 17, 19, and compares those vectors with the order vectors implied by the PGS endpoint class.

The residual phase-bit metric is direct: if public PGS supplies an endpoint class that audit confirms gives the same order vector, residual phase bits are recorded as 0. If no public endpoint class exists, residual phase bits remain the ordinary 2n baseline.
