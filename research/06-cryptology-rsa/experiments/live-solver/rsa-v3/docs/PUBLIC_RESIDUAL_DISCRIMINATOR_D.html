4. Exact predicate hypothesis for D

Name: D_dual_gap_carrier_floor_transport_bound (status: hypothesis)

Why this D (from the live miss). The current public bound uses only the lower gap: 

T      = floor(N / lower.carrier_w)
delta  = |T - upper.carrier_w|
boundF = max(20, floor(1.2 * lower.gap_offset))
       = max(20, (6 * lower.gap_offset) // 5)

# 50-bit pin (measured):
# lower.gap_offset = 24  =>  boundF = 28
# T = 32059651, upper.carrier_w = 32059621
# delta = 30  >  boundF = 28
# excess = delta - boundF = 2
# signed_overshoot = T - upper.carrier_w = +30

Historical same-pair transport notes (rsa-v2 STEP2 analysis) also record upper gap_offset = 14 on this residual pair. The current code ignores the upper gap when sizing the transport bound. D uses both public gaps.

Predicate (deterministic, public only)

def D_dual_gap_carrier_floor_transport_bound(N, lower, upper) -> bool:
    """Hypothesis D. Not implemented in inference yet."""
    lw = int(lower["carrier_w"])
    uw = int(upper["carrier_w"])
    if lw <= 0:
        return False  # same non-positive guard as F_public
    T = N // lw
    delta = abs(T - uw)
    g_lo = int(lower.get("gap_offset") or 0)
    g_up = int(upper.get("gap_offset") or 0)
    if g_lo <= 0:
        g_lo = 20
    if g_up <= 0:
        g_up = 20
    G = g_lo + g_up
    boundD = max(20, (6 * G) // 5)   # 1.2 * dual-gap sum, integer form
    return delta <= boundD

# Pin arithmetic under this hypothesis (using public gap pair 24 + 14):
# G = 38
# boundD = max(20, (6*38)//5) = 45
# delta = 30 <= 45  => D holds on the failing F_public pair
#
# Meaning: D would re-admit the pair that F_public rejects by excess=2,
# using a dual-gap public bound instead of lower-only gap scaling.
