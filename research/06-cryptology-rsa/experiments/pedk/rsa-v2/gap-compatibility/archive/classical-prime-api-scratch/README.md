# Classical Prime API Scratch

These files are exploratory scratch.

They use `gmpy2.prev_prime`, `gmpy2.next_prime`, `gmpy2.is_prime`, or direct
trial divisor counting. That is acceptable as historical trial-and-error, but
it is not the canonical PGS-native evidence path.

Use `../../core-evidence/first_gap_compatibility_check.py` for the current
evidence chain.
