PGS Documentation Correction Audit

Prime Gap Structure defines the integer-level arithmetic structure of prime placement. The documentation must state that source structure first, then describe RH, PNT, zeta language, measurements, and audits as downstream or separate artifacts.

Correction thesis. Prime Gap Structure establishes the exact integer-level arithmetic structure of prime placement (local theorems in PROOF.md). The Riemann Hypothesis is the downstream pole-placement sentence once the same source is expressed through exact DNI-to-zeta compression and source-to-spectral placement is resolved. Documentation fails when it makes the downstream pole sentence the judge of the source arithmetic object.

Sub-Project Contract

Object Repository documentation, public essays, index pages, bridge notes, and continuity files that describe PGS theorem status or consequences.
Invariant PGS source order is preserved: divisor counts -> DNI/GWR -> prime placement -> zeta compression.
Rule State exact arithmetic first. Attach measurement, audit, and unresolved labels to their actual surfaces without downgrading proved PGS laws.

The correction project does not rewrite mathematics to fit rhetoric. It rewrites repository language so the existing arithmetic reality is not demoted by inherited classical framing.
