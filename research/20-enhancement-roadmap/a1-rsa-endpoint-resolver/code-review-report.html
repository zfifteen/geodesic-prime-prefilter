ISSUE-3 · Medium-High · Structural package transport incomplete; emit without fail-closed verify

Location: structural_certificate.build_structural_certificate; resolver.resolve_case

Failure mode: Builder omitted transported_corrected_* transport fields used by verifier deadline checks. Resolver did not refuse emission if verifier would reject a built package.

Test plan: Build package with corrected transport inputs and assert keys present + verify ok; resolve 40-bit and assert emitted cert verifies.

Status: fixed · tests test_issue3_*; resolver now calls verify_certificate before emit and demotes on fail.

Ship-path gate test: test_issue3_verify_on_emit_demotes_bad_package monkeypatches build_structural_certificate to return a rehashed floor-broken package, then calls resolve_case on the 40-bit fixture and asserts demotion (no emit). Removing the verify gate would leave the broken package in structural_certificate and fail the test.

Test plan: Inject unknown closure_status through resolve_case (not helper-only); assert taxonomy-safe residual, no raise.
